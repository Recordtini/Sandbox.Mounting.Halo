# Halo: Combat Evolved (MCC) Mount for s&box

This is some vibe coded slop with Gemini 3 I did to try and get MCC Halo CE into S&Box. So far it gets the file list, reads a lot of textures, and kinda has models. Good jumping off point, feel free to fork or pull or whatever.

## Requirements

-   **Halo: The Master Chief Collection** installed via Steam (AppID 976730).
-   **Halo: CE** installed within MCC.
-   **.NET 7 SDK** (or newer) installed to compile the project.
